# Tef

Desktop terminal for SSH, serial (COM/USB), SFTP, and local shell. Built with React and Tauri.

## Run

```bash
npm install
npm run tauri:dev
```

## Build (Windows)

```bash
npm run tauri:build
```

Installer: `src-tauri/target/release/bundle/nsis/`

## Windows, macOS, and Linux via GitHub

Push to `main`, then **Actions → Release → Run workflow**. See `TAURI.md` for details.
